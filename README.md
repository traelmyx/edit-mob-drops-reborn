# Edit Mob Drops Reborn

Add drops to mobs from a config file: to every mob, to monsters only, to bosses, to your own groups of mobs, or to one mob type, each with its own chance and stack size. You can also clear a mob's normal drops.

Port of [Edit Mob Drops](https://github.com/Powerthegreat/EditMobDrops) by Powerthegreat to Minecraft 1.21.1, for NeoForge.

## Building

`./gradlew build` builds the jar and runs the game tests.
